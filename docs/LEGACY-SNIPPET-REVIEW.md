## How to review

1. Open an entry in Craft using its link below.
2. Check the lead, categories, heading structure and technical accuracy.
3. Review code-language labels; the importer preserved existing labels except `html` → `xml`.
4. Add an independent teaser, optional reading time and featured selection. No code was extracted into teasers.
5. Preview the article, then enable it when ready. The importer skips existing source UIDs, so rerunning it will not disable, overwrite or duplicate reviewed entries.

Original URL mappings and the one custom SEO record are preserved in the ignored `storage/temp/legacy-import-result.json` and `storage/temp/legacy-snippets.json`. Redirects are prepared in `storage/temp/legacy-redirects.json`; they are **not active** yet, since targets remain disabled.
