# Craft CMS Plugin Site Health check

Plugin to check for and report on various website cms and server environment variables

## Features

Health Checks:

- Used disk space
- Database connection
- Debug mode + Environment settings
- Deprecation warnings
- System requirements
- Queue failed
- Available updates
- Used PHP Version
- Needed database migrations

## Requirements

- Craft CMS 4
- PHP 8
